# Sistema de Gestión de Productos y Pedidos para una Cafetería Universitaria

## 1. Descripción

Sistema desarrollado en Python para gestionar los productos y pedidos de una cafetería universitaria. Permite registrar, consultar, buscar, editar y eliminar productos, así como realizar pedidos y gestionar pagos.

El proyecto aplica programación modular y almacenamiento de información mediante archivos de texto.

## 2. Tecnologías utilizadas

- Python 3.12
- Visual Studio Code
- Git
- GitHub

## 3. Funcionalidades

- Registrar productos.
- Mostrar productos disponibles.
- Buscar productos.
- Editar productos.
- Eliminar productos.
- Registrar y atender pedidos.
- Seleccionar métodos de pago.
- Generar comprobantes de pedidos.
- Guardar y leer información mediante archivos de texto.

## 4. Estructura del proyecto

- `main.py`: contiene el menú principal.
- `producto.py`: contiene la clase Producto.
- `gestion_productos.py`: administra los productos y las operaciones del sistema.
- `productos.txt`: almacena la información de los productos.
- `prototipo_v3.8.2.py`: contiene el prototipo inicial.
